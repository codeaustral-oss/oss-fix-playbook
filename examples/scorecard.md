# Task Scorecard

Use this before starting bounty or maintainer-requested work.

| Signal | Points | Good Evidence |
| --- | ---: | --- |
| Acceptance clarity | 20 | Expected behavior, constraints, and done condition are visible. |
| Maintainer/payment confidence | 20 | Active maintainer, platform payout, or recent project response. |
| Reproducibility | 20 | The issue can be reproduced locally or verified through CI. |
| Setup speed | 15 | Project can run without unusual private services. |
| Scope fit | 15 | Change can be reviewed in a focused pull request. |
| Reputation value | 10 | Useful project, respectful thread, and non-duplicate work. |

Start work at 75+ points. Ask a clarifying question or pass below that threshold.
